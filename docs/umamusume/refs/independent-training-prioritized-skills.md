# Independent training's prioritized skills

Retrieved 2026-11-04. Independent training's JP name is 自主トレ育成, added to the JP client on 2026-06-29
([official announcement](https://x.com/uma_musu/status/2071429458431811759)). It is a different feature
from おまかせ育成 (also called オート育成), Auto-Train; JP guides compare the two. An earlier version of this
page, retrieved 2026-10-31, cited おまかせ育成 guides as if they described independent training.

## Event choices

Two JP guides to 自主トレ育成 state the rule, and four おまかせ育成 guides describe the same rule for that mode:

- With no prioritized skill set, the run takes the top option of every event.
- A prioritized skill makes the run take the option that gives it.

The guides give the same example: the 安心沢 (Anshinzawa) acupuncture event's top option is the high-risk
one, so they list Straightaway Recovery or Corner Recovery ○, which a lower option gives, to avoid it.

Not stated by any source: which option the run takes when some prioritized skills are set but none is
offered by the event (presumably the top one), and which option wins when two listed skills sit on
different options of one event. The 自主トレ育成 guides describe the JP client; Global is assumed to match.

## Training hints

No source found says whether prioritized skills change which training independent training picks, for
example toward a support card showing a hint for a listed skill. Searches in Japanese and English found
no test of it. Every source that describes the setting's effect names event options only.

- [Game8, 自主トレのやり方と設定おすすめ](https://game8.jp/umamusume/794628) (updated 2026-06-30) describes the
  setting as 「育成イベントなどで優先して取得するスキルヒントを最大10個まで設定可能です。（※ヒントLvが最大のスキルは重視対象外）」:
  hints to acquire first "at training events and the like", excluding skills whose hint level is already
  at maximum. "And the like" leaves other sources open but does not name training.
- The same guide and 神ゲー攻略 report that 自主トレ育成 collects support-card skills less reliably than
  おまかせ育成 with the same deck; ウィングオブハート says its support-card hint collection is unstable.
