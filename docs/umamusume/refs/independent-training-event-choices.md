# Independent training's event choices

Retrieved 2026-10-31. Three Japanese strategy guides describe the same rule for おまかせ育成, the JP name
of independent training. No Global or English source found states it; uma.guide's
[independent-training guide](umaguide-independent-training.md) says only that the run targets the
prioritized skills.

- With no prioritized skill set, the run takes the top option of every event.
- A prioritized skill makes the run take the option that gives it.

Game8 and ウマ娘ラボ give the same example: the 安心沢 (Anshinzawa) acupuncture event's top option is the
high-risk one, so they list Straightaway Recovery or Corner Recovery ○, which a lower option gives, to
avoid it.

Not stated by any source: which option the run takes when some prioritized skills are set but none
is offered by the event (presumably the top one), and which option wins when two listed skills sit
on different options of one event. The guides describe the JP client; Global is assumed to match.
