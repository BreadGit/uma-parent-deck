# Umamusume game information

This directory is for game information only: mechanics, terminology, saved guides, and reference
datasets. Keep project architecture, implementation notes, plans, and progress reports outside it.
Project behavior is documented in the [root README](../../README.md) and [tool glossary](../GLOSSARY.md).

Use these local references before browsing for game information. Check source dates and whether a
rule applies to Global or JP. The [curated reference index](refs/README.md) describes evidence and conflicts.

- [Game glossary](GLOSSARY.md): Global terminology and community equivalents.
- [New player guide](new-player-info.txt) and [mechanics guide](mechanics.txt): searchable text of
  the Global reference PDFs stored alongside them.
- [Curated references](refs/README.md): spark generation, inheritance, race odds, rating tables,
  support effects, and saved scenario guides.
- [Two Fuji independent-training runs](fuji-independent-training-runs.json): user-reported inputs,
  race finishes, final stats, fans and ratings. Two observations, not a calibration dataset.
- [Loopacord workbook](loopacord-independent-training-research.xlsx) and
  [card data](loopacord-card-data.csv): independent-training measurements, including chain completion.
- [Fujikiseki report](fujikiseki-insights-2026-09-04.html), [CSV](fujikiseki-card-table.csv), and
  [JSON](fujikiseki-card-table.json): saved independent-training observations.
